ReminderSnap 1.0 — macOS setup
================================

System requirements
-------------------
• macOS 13 Ventura or newer
• Apple Silicon or Intel Mac
• Apple Reminders configured with an iCloud list named “NYU”

Install
-------
1. Unzip ReminderSnap-1.0-macOS-universal.zip.
2. Drag ReminderSnap.app into your Applications folder.
3. The first time you open it, Control-click ReminderSnap.app, choose Open,
   then choose Open again. This one-time step is needed because this free,
   personal build is not notarized through Apple's paid developer program.
4. When macOS asks, allow ReminderSnap to access Reminders.

Use
---
1. Open ReminderSnap.
2. Drop one or more Gradescope or WebAssign screenshots into the window.
3. Review the extracted titles and deadlines.
4. Choose Add Selected to Reminders.

Privacy
-------
Screenshot text recognition runs locally with Apple's Vision framework.
ReminderSnap does not upload screenshots or assignment data.

Troubleshooting
---------------
• If “NYU” is not found, create that list in Reminders or change the list name
  at the top of ReminderSnap.(I'm a NYU student so I've set the defult as NYU LOL)
  
• If access was denied, open System Settings → Privacy & Security → Reminders
  and enable ReminderSnap.
  
• Timed reminders include a notification at the due time. Date-only deadlines
  are created as all-day reminders.
